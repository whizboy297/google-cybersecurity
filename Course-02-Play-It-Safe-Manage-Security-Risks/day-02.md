## 1. CIA Triad

The CIA triad is a foundational security model used to set up security policies and systems.

CIA stands for:

### Confidentiality
Ensures that only authorized users can access specific information.

### Integrity
Ensures that an organization's data is verifiably correct, authentic, and reliable.

### Availability
Ensures that data is accessible to authorized users when needed.

### Key idea

**Confidentiality → Who can access the data?**  
**Integrity → Is the data correct and trustworthy?**  
**Availability → Can authorized users access it when needed?**

## 2. NIST Cybersecurity Framework (CSF)

NIST stands for:

**National Institute of Standards and Technology**

The NIST Cybersecurity Framework (CSF) is a voluntary framework consisting of standards, guidelines, and best practices that organizations can follow to manage cybersecurity risk.

### Six Core Functions

The six core functions of the CSF are:

1. **Govern**
2. **Identify**
3. **Protect**
4. **Detect**
5. **Respond**
6. **Recover**

### Identify
Understanding an organization's assets, risks, and policies to establish a strong foundation for managing cybersecurity threats.

### Protect
Implementing safeguards to protect an organization's assets and data.

### Detect
Identifying cybersecurity events and potential threats.

### Respond
Taking action to contain and address security incidents.

### Recover
Returning affected systems back to normal operation.

## 3. OWASP Security Principles

I learned several OWASP security principles:

- **Minimize the attack surface**
- **Principle of least privilege**
- **Defense in depth**
- **Separation of duties**
- **Keep security simple**
- **Fix security issues correctly**

### Examples

**Minimize the attack surface:**  
Disable unnecessary software features or services that could provide attackers with opportunities to exploit vulnerabilities.

**Least privilege:**  
Give users only the access and permissions they need.

**Defense in depth:**  
Use multiple layers of security so that if one security measure fails, others can provide protection.

**Separation of duties:**  
Divide responsibilities between different people to reduce the risk of mistakes or misuse.

## 4. Security Audits

A security audit is a review of an organization's security controls, policies, and procedures against a set of expectations.

### Purposes of Internal Security Audits

- Identify organizational risk
- Assess controls
- Correct compliance issues

### Common Elements of Internal Audits

1. Establishing the scope and goals
2. Conducting a risk assessment
3. Completing a controls assessment
4. Assessing compliance
5. Communicating results

### Audit Questions

An internal security audit may ask:

- What is the audit meant to achieve?
- Which assets are most at risk?
- Are current controls sufficient to protect those assets?
- What controls and compliance regulations need to be implemented?

---

## 5. Security Controls

Security controls can be grouped into three categories:

### Administrative Controls
Policies, procedures, and rules that guide security management.

### Technical Controls
Technology-based measures used to protect systems and data.

### Physical Controls
Physical measures used to protect facilities, equipment, and other assets.

### Easy way to remember

**Administrative = Rules**  
**Technical = Technology**  
**Physical = Physical protection**

---

## 6. Controls Assessment

A controls assessment involves closely reviewing an organization's existing assets and evaluating potential risks to those assets in order to ensure internal controls and processes are effective.

---

## 7. Communicating Audit Results

When communicating the results of an internal security audit to stakeholders, the communication should include:

- A summary of the audit's scope and goals
- A list of risks and compliance requirements that need to be addressed
- Recommendations for improving the organization's security posture

## Key Takeaways

- The **CIA triad** consists of Confidentiality, Integrity, and Availability.
- **NIST** stands for National Institute of Standards and Technology.
- The NIST CSF provides standards, guidelines, and best practices for managing cybersecurity risk.

- Security audits review controls, policies, and procedures.
