## What I Learned

### CISSP's Eight Security Domains

I learned about the eight security domains:

1. Security and Risk Management
2. Asset Security
3. Security Architecture and Engineering
4. Communications and Network Security
5. Identity and Access Management
6. Security Assessment and Testing
7. Security Operations
8. Software Development Security

### Threats, Risks, and Vulnerabilities

- **Threat:** Something that can cause harm to an asset.
- **Vulnerability:** A weakness that can be exploited by a threat.
- **Risk:** The potential for a threat to exploit a vulnerability and negatively affect an asset.

### Key Impacts

Threats, risks, and vulnerabilities can result in:

- Financial damage
- Identity theft
- Damage to reputation

### High-Risk Assets

Information protected by regulations or laws can be considered a **high-risk asset**. If compromised, there can be a severe negative impact on an organization's finances, operations, or reputation.

## NIST Risk Management Framework (RMF)

I learned the seven steps of the NIST Risk Management Framework:

**Prepare → Categorize → Select → Implement → Assess → Authorize → Monitor**

The RMF provides a structured approach to managing cybersecurity risks.

## Security Assessment and Testing

Security professionals may:

- Conduct security control testing
- Collect and analyze data
- Perform security audits
- Monitor for risks, threats, and vulnerabilities

## Security Operations

The security operations domain focuses on conducting investigations and implementing preventative measures.

## Key Takeaway

Day 1 helped me understand that cybersecurity involves more than responding to attacks. Security professionals must identify threats and vulnerabilities, understand risk, protect important assets, and use established frameworks to manage security effectively.
