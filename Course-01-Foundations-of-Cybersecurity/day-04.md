# Day 04

## Date
August 3, 2026

## Course
Course 1 - Foundations of Cybersecurity

## Module
Module 3 - Protect against threats, risks, and vulnerabilities

## Lessons Completed

- SIEM (Security Information and Event Management) tools
- Security playbooks
- Network protocol analyzers
- Introduction to the Linux operating system
- Programming languages used in cybersecurity

## Key Concepts

- SIEM tools collect and analyze security logs from multiple systems to detect suspicious activity.
- Playbooks provide standardized step-by-step procedures for responding to security incidents.
- Network protocol analyzers help security analysts inspect network traffic to identify threats and troubleshoot issues.
- Linux is one of the most widely used operating systems in cybersecurity because of its stability, flexibility, and powerful command-line tools.
- Programming languages such as Python, SQL, and Bash help automate tasks, analyze data, and improve security operations.

## New Terms

- SIEM (Security Information and Event Management)
- Playbook
- Network Protocol Analyzer
- Linux
- Bash
- Python
- SQL

## My Notes

- SIEM tools help security analysts monitor systems and quickly identify potential threats.
- Playbooks ensure incidents are handled consistently by following documented procedures.
- Network protocol analyzers allow analysts to examine packets traveling across a network.
- Learning Linux is essential because many cybersecurity tools and servers run on Linux.
- Programming skills will become increasingly important for automation, scripting, and data analysis.

## Questions

- How do SIEM tools detect suspicious behavior?
- Which Linux commands should I master first?
- When should a security analyst use Python instead of Bash?
- What is the difference between Wireshark and other network protocol analyzers?

## Summary

Today I learned about several essential tools and technologies used by security analysts. I now understand the purpose of SIEM tools, playbooks, network protocol analyzers, Linux, and programming languages. These technologies form the foundation for monitoring, investigating, and responding to cybersecurity threats efficiently.# Day 04
