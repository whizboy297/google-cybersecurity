## 1. Network Protocols

Network protocols are rules used by two or more devices on a network to describe the order of delivery and structure of data.

### Important Protocols

- **ARP (Address Resolution Protocol):** Determines the MAC address of the next router or device on the path.
- **DNS (Domain Name System):** Translates internet domain names into IP addresses.
- **HTTP:** Provides communication between clients and website servers.
- **HTTPS:** Provides secure communication between clients and servers.
- **TCP:** Allows two devices to form a connection and stream data.
- **SFTP:** Securely transfers files between devices over a network.
- **SSH:** Creates a shell with a remote system.
- **SNMP:** Monitors and manages devices on a network.

---

## 2. Wireless Protocols

### IEEE 802.11 (Wi-Fi)

IEEE 802.11 is a set of standards that defines communication for wireless LANs.

### WPA

Wi-Fi Protected Access (WPA) is a wireless security protocol used for devices connecting to the internet.

---

## 3. Virtual Private Networks (VPNs)

A VPN is a network security service that changes a device's public IP address and masks its virtual location to help keep data private when using a public network.

### Encapsulation

Encapsulation is a process performed by a VPN service that protects data by wrapping sensitive data inside other data packets.

---

## 4. Firewalls

A firewall is a network security device that monitors traffic to or from a network.

It can allow or deny traffic based on defined security rules.

### Stateful Firewall

A stateful firewall keeps track of information passing through it and proactively filters out threats.

### Stateless Firewall

A stateless firewall operates based on predefined rules and does not keep track of information from data packets.

### Port Filtering

Port filtering is a firewall function that blocks or allows certain port numbers to limit unwanted communication.

### Cloud-Based Firewalls

Cloud-based firewalls are software firewalls hosted by a cloud service provider.

---

## 5. Security Zones

A security zone is a segment of a company's network that protects the internal network from the internet.

### Uncontrolled Zone

The portion of the network outside the organization.

Example: the Internet.

### Controlled Zone

A subnet that protects the internal network from the uncontrolled zone.

### Demilitarized Zone (DMZ)

A network zone used for public-facing services such as:

- Web servers
- Proxy servers
- DNS servers

### Restricted Zone

A zone used to protect highly confidential information that is only accessible to employees with certain privileges.

---

## 6. Proxy Servers

A proxy server fulfills the requests of its clients by forwarding them to other servers.

### Forward Proxy

A forward proxy regulates and restricts a person's access to the internet.

**Client → Forward Proxy → Internet**

### Reverse Proxy

A reverse proxy regulates and restricts the internet's access to an internal server.

**Internet → Reverse Proxy → Internal Server**

---

## 7. Network Security Concepts

### Network Segmentation

Network segmentation is a security technique that divides a network into segments.

### Subnetting

Subnetting is the subdivision of a network into logical groups called subnets.

---

## Key Takeaways

- Network protocols define how devices communicate and how data is delivered.
- ARP helps determine the MAC address of the next device on a network path.
- IEEE 802.11 defines Wi-Fi communication standards.
- VPNs help protect privacy when using public networks.
- Firewalls monitor and filter network traffic.
- Stateful firewalls track information passing through them.
- Stateless firewalls use predefined rules without tracking packet information.
- Port filtering controls communication through specific ports.
- Security zones separate networks according to their level of access and trust.
- A DMZ is commonly used for public-facing services.
- Forward proxies control client access to the internet.
- Reverse proxies control internet access to internal servers.
- Network segmentation and subnetting divide networks into smaller sections.
